qgis2web Web Map

A browser-based presentation of selected Globasnitz layers exported from QGIS with qgis2web and rendered with Leaflet.

Open source dataset in ARCHE Back to Web Mapping Overview

About this qgis2web example

The embedded map is a static web export based on the IUENNA open geodata package for Globasnitz. The qgis2web plugin translates QGIS layers, attributes, symbology, and selected map interactions into browser-ready files; this export uses Leaflet as its map library.

The page is intended as a lightweight discovery and visualization interface. It does not replace the source GeoPackage or its repository metadata, and web styling or interactivity may differ from the original QGIS project. For citation, reuse, licensing, and access information, the corresponding ARCHE record is the authoritative reference.

qgis2web is useful for publishing selected GIS layers without a dedicated application server. Its main trade-offs are that complex QGIS styling may require manual adjustment after export and that large vector datasets can affect browser performance. These are technical characteristics of the web-delivery method rather than interpretations of the archaeological data.
