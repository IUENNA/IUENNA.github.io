The BYOAI Philosophy

In Digital Humanities and classical archaeology, research data must remain interoperable, authoritative, and reproducible. Instead of trapping researchers inside a single commercial chatbot or requiring browser visitors to download heavy in-browser language models, IUENNA embraces BYOAI (Bring Your Own AI):

„We provide the authoritative archaeological data, open protocols, and machine-readable endpoints. You bring the AI engine of your choice — whether that is a 100% offline local model on your laptop, an open-source research agent, or your preferred desktop workspace.“

By adhering strictly to FAIR data principles (Findable, Accessible, Interoperable, Reusable), IUENNA ensures that our 356+ GB corpus archived in ARCHE (ACDH-CH / ÖAW) can be explored seamlessly by modern AI assistants without recurring server costs or commercial lock-in.

1. Model Context Protocol (MCP)

The Model Context Protocol (MCP) is the open-standard communication protocol connecting AI assistants and agentic IDEs to external data sources. It functions like a universal „USB-C cable for AI models“.

The IUENNA MCP server runs locally on your machine with zero external dependencies and exposes four specialized archaeological tools to any MCP-compliant client (including Open-WebUI, LibreChat, Claude Desktop, Cursor, Zed, and Antigravity).

Setup for Claude Desktop / Cursor / Open-WebUI

Add the following block to your client's configuration file (e.g. claude_desktop_config.json):

claude_desktop_config.json 
{
  "mcpServers": {
    "iuenna": {
      "command": "python3",
      "args": [
        "-c",
        "import urllib.request; exec(urllib.request.urlopen('https://raw.githubusercontent.com/IUENNA/IUENNA.github.io/main/mcp/server.py').read().decode())"
      ]
    }
  }
}

Alternative: Clone the repository and run python3 mcp/server.py or node mcp/index.mjs directly.

3. The llms.txt Web Standard

The llms.txt standard provides structured markdown summaries specifically designed for web-crawling LLMs and conversational search engines (e.g. Perplexity, ChatGPT Search, Gemini, and Claude).

Whenever you prompt an external AI to research the Jauntal micro-region, simply provide the canonical URL:

Canonical llms.txt Link 
https://iuenna.github.io/llms.txt

This ensures the model grounds its answers strictly on verified ARCHE archival handles, authoritative excavation reports (Hans Winkler, Franz Glaser, Dominik Hagmann), and exact coordinates rather than hallucinatory speculation.

4. The Researcher's Cookbook

Practical code snippets and integration patterns to kickstart your research pipelines. Choose your preferred environment:

Run a 100% private, offline RAG pipeline on your own computer using Python and Ollama (e.g. with llama3.2 or mistral). No API keys or external server calls required:

query_iuenna_local.py 
import urllib.request
import json
import ollama

# 1. Fetch live findspots from IUENNA
url = "https://iuenna.github.io/data/arche_places.json"
req = urllib.request.Request(url, headers={"User-Agent": "BYOAI-Researcher/1.0"})
with urllib.request.urlopen(req) as resp:
    places = json.loads(resp.read().decode())

# 2. Filter relevant sites (e.g. related to 'Hemmaberg' or 'Globasnitz')
context = [p for p in places if "hemmaberg" in p["title"].lower() or "globasnitz" in p["title"].lower()]

# 3. Ask your local LLM with exact grounding
prompt = f"""You are an archaeological research assistant. 
Based ONLY on the following IUENNA findspot data, summarize the locations and archaeological contexts:
{json.dumps(context[:5], indent=2)}

Question: What are the primary coordinates and known contexts for the Hemmaberg sites?"""

response = ollama.chat(model='llama3.2', messages=[{'role': 'user', 'content': prompt}])
print(response['message']['content'])

If you host Open-WebUI or LibreChat for your research institute or personal workspace, connect the IUENNA MCP server as an external tool:

  1. Navigate to Settings → Tools → Add Tool (or MCP Servers).
  2. Set Protocol to stdio.
  3. Set Command to python3 and pass the path to mcp/server.py.
  4. Save. Your team can now invoke @iuenna search for Hans Winkler reports directly within your shared chat interface!

Inspect and extract findspots directly inside your terminal with curl and jq:

bash / zsh 
# Extract all sites mentioning 'Münzen' or 'Globasnitz' with coordinates
curl -s https://iuenna.github.io/data/arche_places.json | \
  jq '.[] | select(.title | test("Globasnitz|Hemmaberg"; "i")) | {title, lat, lng, geonames_id}'
