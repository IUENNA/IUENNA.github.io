# IUENNA Website Changelog

This changelog records user-visible and technically relevant changes to the IUENNA GitHub Pages website and its associated discovery interfaces.

## 2026-09-12

### Footer: direct link to the source repository

- Added a direct **GitHub Repository** link to the website footer, pointing to `https://github.com/IUENNA/IUENNA.github.io`.
- The intended footer order is now: `© 2026 IUENNA Project | GitHub Repository | Legal Notice & Privacy Policy | CC BY 4.0`.
- The shared navigation script (`scripts/nav.js`) ensures that the repository link is added consistently to public IUENNA pages that use the common footer/navigation setup.
- This explicitly distinguishes the deployed GitHub Pages website (`https://iuenna.github.io/`) from the underlying source-code repository on GitHub.
